# 🎮 Hangman Game

## 📌 Description

Hangman Game is a simple **command-line word guessing game developed using Python**. The player needs to guess the hidden word one letter at a time within a limited number of attempts.

This project demonstrates basic Python programming concepts such as loops, conditional statements, lists, strings, functions, and user input.

## ✨ Features

* 🎲 Randomly selects a word
* 🔤 Allows the player to guess letters
* ❤️ Limited number of attempts
* ❌ Detects incorrect guesses
* 🔁 Prevents repeated guesses
* 📊 Displays the progress of the word
* 🏆 Shows the final win or loss result

## 🛠️ Technologies Used

* **Python**
* **Random Module**
* **Command Line Interface (CLI)**

## 🎯 How to Play

1. Start the game.
2. A random word is selected by the program.
3. The word is displayed as underscores.
4. Enter one letter at a time.
5. Correct guesses reveal the corresponding letters.
6. Incorrect guesses reduce the number of remaining attempts.
7. Guess the complete word before the attempts run out to win.

## 💻 Example

```text
🎮 Welcome to Hangman!

Word: _ _ _ _ _ _

Enter a letter: a

Correct Guess!

Word: _ a _ _ _ _

Enter a letter: z

Wrong Guess!
```
